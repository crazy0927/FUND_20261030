# 統一奔騰基金 × 加權大盤指數與融資籌碼分析看盤系統 (FUND_20261030)

本專案提供自臺灣證券交易所 (TWSE) 與統一投信官網同步之歷史數據資料庫，以及專為電腦桌面寬螢幕打造之三竹金融風格互動看盤工作站。

---

## 📁 核心資料庫架構 (`股市資料庫.db`)

本地 SQLite 資料庫包含以下主要資料表：
1. **`基金` Table**：
   - 收錄「統一奔騰基金」歷史淨值（114/01/01 至動態今日最新數據）。
   - 完整技術指標欄位：前日淨值、漲跌、漲跌幅、20日平均(中軌)、布林上軌(天花板)、布林下軌(地板)、5MA、10MA、20MA、60MA、K值(快線)、D值(慢線)、RSV(今日成績排名)、均線排列隊形、交叉訊號。
2. **`大盤資料表` Table**：
   - 臺灣證券交易所發行量加權股價指數歷史資料（開盤指數、最高指數、最低指數、收盤指數）。
3. **`融資餘額` Table**：
   - 臺灣證券交易所信用交易融資融券市場籌碼餘額與當日增減（張數與金額仟元）。
4. **`00981A` Table**：
   - 主動統一台股增長歷史價格與技術指標對齊表。

## 🖥️ 互動看盤系統與網頁應用程式

* **`mitake_fund_desktop.html` / `code_artifact.html`**：
  - **電腦桌面大寬幅四圖聯動看盤工作站**。
  - **【圖一：統一奔騰基金】**：以「立體淨值圓點 (Dots) + 走勢連線 + 布林通道 (BBAND 20日, ±2SD) + 波段高低點標註」呈現。
  - **【圖二：9日KD 體溫計】**：9K、9D 雙線與 >80 超買暗紅警戒、<20 超賣翠綠著色區塊。
  - **【圖三：全市場融資籌碼統計圖】**：金黃色融資餘額折線 + 紅增綠減直方柱（零軸基準線）+ 張數與億元刻度對照。
  - **【圖四：加權大盤指數 (TAIEX) K 線圖】**：標準台股開高低收紅漲綠跌實體蠟燭線 + 5MA/20MA 均線。
  - **全域操作**：支援滑鼠滾輪自由縮放、滑鼠按住拖曳平移、金色十字查價線一口氣穿透四圖、鍵盤左右方向鍵逐日步進、頂部週期一鍵切換 (近1月/近3月/近半年/近1年/全部)、以及右側「六大指標智能診斷面板」。
* **`mitake_fund_interactive.html`**：
  - 仿三竹手機 APP 界面之基金專用看盤頁面。
* **`mitake_00981a_interactive.html`**：
  - 仿三竹 00981A 原始 K 線互動看板。

## 🐍 Python 數據抓取與計算腳本

* **`fetch_twse_taiex.py`**：臺灣證券交易所加權指數歷史數據抓取腳本。
* **`fetch_twse_margin.py`**：TWSE 大盤融資融券歷史籌碼抓取腳本。
* **`fetch_fund_nav.py`**：統一奔騰歷史淨值抓取、技術指標計算與資料庫寫入程式。
* **`generate_mitake_desktop.py`**：四圖聯動電腦桌面看盤系統 HTML 產生器。
* **`generate_mitake_fund_app.py`**：手機風格看盤系統 HTML 產生器。
* **`build_00981a_table.py`**：00981A 資料表建立與計算腳本。
